# עדכון מלאים מקובץ Excel

המערכת מוכנה לעדכן את טבלת המלאים מקובץ Excel.

## מבנה הקובץ הנדרש

קובץ ה-Excel צריך לכלול את העמודות הבאות:
- **ספק** - שם הספק
- **שם המוצר** - שם הפריט (יכול להיות עם אימוג'י של קטגוריה)
- **כמות במלאי** - הכמות הנוכחית במלאי
- **כמה להזמין** - כמות מינימלית להזמנה (minStockLevel)

הקטגוריות מזוהות אוטומטית לפי אימוג'י או שם:
- 🍷 יין → `wine`
- 🍺 אלכוהול → `alcohol`
- 🥤 משקאות → `soft_drink`
- אחר → `other`

## שימוש

### אופציה 1: ייבוא מלא (מומלץ)
הרץ את הסקריפט הראשי שיבצע את שני השלבים:

```bash
cd c:\barApp\barApp-backend\data
node import_inventory.mjs "c:\Users\edena\Downloads\bar-managment.xlsx"
```

### אופציה 2: שלבים נפרדים

**שלב 1: פרסור קובץ ה-Excel**
```bash
cd C:\barApp\barApp-frontend
node parse-inventory.mjs "c:\Users\edena\Downloads\bar-managment.xlsx"
```

זה יוצר קובץ `inventory_update.json` בתיקיית `barApp-backend/data/`

**שלב 2: עדכון המלאים בבסיס הנתונים**
```bash
cd c:\barApp\barApp-backend\data
node update_inventory.mjs
```

## מה הסקריפט עושה?

1. **פרסור Excel**: קורא את קובץ ה-Excel, מזהה את העמודות והקטגוריות, וממיר ל-JSON
2. **עדכון מלאים**: 
   - מחפש כל פריט לפי שם וספק
   - מעדכן את `stockQuantity` (כמות במלאי)
   - מעדכן את `minStockLevel` (כמה להזמין)
   - אם הפריט לא נמצא, הוא יודפס כ-"Not found" (לא נוצר אוטומטית)

## הערות

- הסקריפט מעדכן רק פריטים קיימים - לא יוצר פריטים חדשים אוטומטית
- אם אתה רוצה ליצור פריטים חדשים אוטומטית, פתח את `update_inventory.mjs` ובטל הערה על החלק שיוצר פריטים חדשים
- הסקריפט מחפש התאמה לפי שם + ספק, ואם לא מוצא - מחפש רק לפי שם
